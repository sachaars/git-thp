# Claia Demo

Ce dépôt contient une maquette très simple d’un SaaS nommé **Claia**. Il propose quelques pages statiques :

- `index.html` : page d’accueil.
- `login.html` et `register.html` : formulaires d’authentification.
- `dashboard.html` : exemple de tableau de bord avec une navigation latérale.
- `faq.html` : une courte foire aux questions.

Les fichiers se trouvent dans le dossier `claia/`. Aucune logique serveur n’est incluse ; il s’agit simplement d’un prototype HTML/CSS.
